# Sinais e sistemas

Exemplos de sinais e sistemas usados nas disciplinas ECM307 e ECA414 do Instituto Mauá de Tecnologia: modulação AM e FM, séries e transformada de Fourier, sistemas lineares, Laplace, tempo discreto, análise de voz e síntese sonora.

**Linguagens:** Matlab · Simulink · Python (Jupyter) · Pure Data

## Estrutura
| Pasta | Conteúdo |
|---|---|
| 1 - AM | Modulação em amplitude |
| 2 - Fourier | Série e transformada de Fourier, vogais |
| 3 - Sistemas lineares | Convolução, filtros, síntese de Fourier |
| 4 - Apresentações | Slides das aulas (PDF) |
| 5 - Laplace | Transformada de Laplace, circuitos RLC |
| 6 - Análise de voz | Análise espectral de voz |
| 7 - FM | Modulação em frequência (Matlab e Simulink) |
| 8 - Notas | Notas de aula |
| 9 - Tempo discreto | Sinais discretos, média móvel, filtros FIR |
| 10 - SistemasDinamicosSinais | Analogia entre vetores e sinais |
| 11 - Arquivos de Audio | Áudios usados nos exemplos |
| 12 - Pure data | Patches de síntese sonora |

## Como usar
Matlab R2020b ou mais novo com Signal Processing Toolbox; os scripts marcados como Octave rodam no GNU Octave. Os notebooks abrem no Google Colab e os patches no Pure Data.
